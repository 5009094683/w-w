| | FlavorGPT | FlavorAI | FlavorAI API |
| --- | --- | --- | --- |
| What it is | AI chat and agent workspace | AI orchestration platform | One API in front of your AI providers |
| Used by | People and teams, directly | Enterprise applications | Developers and applications |
| What it does | Chats with many models, uses your tools and data, runs agents | Routes, cross-verifies and monitors AI workloads across models | Manages your AI providers and APIs behind a single OpenAI-format endpoint |
| How to get it | [flavor-ai.tech](https://flavor-ai.tech/) | [Contact us](/contact-us) | Enterprise license, hosted on your server |

FlavorAI is built on the foundation of the FlavorGPT architecture, and the FlavorAI API is the API product in the same family.
